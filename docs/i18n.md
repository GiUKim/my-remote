# Languages

The app shows its interface in 12 languages: 한국어, English, 日本語, 简体中文, 繁體中文, Español, Français,
Deutsch, Português (Brasil), Русский, Tiếng Việt, Bahasa Indonesia. Each PC has one setting for the whole app. The
start screen, the host window, the client app's PC list and a remote session's toolbar all change it, and a change
in one place reaches the others at once. The first start follows the system's language, else English.

## How it works

- **The Korean text is the key** (as with gettext). The code says `t('키 복사')`. The catalog
  `host/i18n/<name>.json` maps that source to `{ "en": …, "ja": …, … }`. A missing language falls back to English,
  then to the Korean. Placeholders are `{0}`, `{1}`. A plural is an object of Intl.PluralRules categories
  (`one`/`other`, Russian `one`/`few`/`many`/`other`), chosen by the first argument.
- **Markup:** elements carry `data-i18n` (text), `data-i18n-html` (text with `<b>`, `<i>`, `<kbd>`, `<br>`),
  `data-i18n-title` / `-placeholder` / `-aria`. `I18N.apply()` relabels them and keeps the source on the element.
- **Four surfaces, five catalogs:**

  | Catalog | Used by |
  |---|---|
  | `host.json` | `host/host.html`, `host/host.js`, `host/main.js` (dialogs, tray) |
  | `page.json` | the client page (`host/client.template.html`): toolbar, dialogs, messages |
  | `page-report.json` | the 진단 report's lines (English only: the report goes to whoever helps) |
  | `client.json` | the start screen, the PC list, the client app's dialogs and drag picture |
  | `loader.json` | the loader (`pangmote-client.html`) |

- **The setting** is `<appData>/my-remote/settings.json` `{ "lang": … }` (`host/settings.js`). Both programs (host
  and client app) watch it. Isolated runs (self-test, local trial, bench) keep their own file in their throwaway
  profile and start in Korean, which their checks read, unless `PANGMOTE_LANG` (or `MY_REMOTE_LANG`, its name before 0.10.0) names another language.
- **The client page's texts.** The page must fit the loader's 40-chunk reply, so it carries no catalog. Its texts
  reach it three ways: the loader (from this version) brings `page.json` (`__mrBoot.i18n`); the page keeps what the
  host sent for that very page (`mr_i18n:<page hash>:<lang>`); and once connected the host answers
  `{t:'lang', l}` with `{t:'strings', l, s}`. The last one also serves loaders handed out before the languages.
- **The language picker** is the hidden `<select id="lang">`, shown as a button with the flag and the language's
  own name that opens a list (`I18N.fillSelect` / `picker`). A native list cannot show pictures, and Windows draws
  flag emoji as two letters, so the flags are small SVGs drawn in `host/i18n.js` (made by a script from each flag's
  construction). A flag stands for the country whose code the language carries: English the United States (the
  translations use US spelling), 繁體中文 Taiwan (zh-TW), Português Brazil. Apps sold in mainland China use Hong
  Kong's flag or none for Traditional Chinese; change `FLAGS['zh-TW']` for that.

- **Release notes** (`release/notes/<version>.json`) are written in Korean and English: the shell's updater
  (`app/updater.js`, which an update cannot replace) passes on only those two, so every other language shows the
  English notes.

## Adding or changing a text

1. Write the Korean in the code, as before. Never assemble a sentence from pieces: use `t('… {0} …', x)`.
   `release/i18n-sources.js` reports a template literal with `${}` and Korean text, and unmarked Korean in markup.
2. Add its entry to the catalog, with every language: `node release/i18n-sources.js --missing` lists what is missing.
3. Run `node release/test-i18n.js` (CI runs it). It checks every text is translated and nothing unused is left;
   placeholders and tags match the source; no Korean is left in a translation; plural forms are complete; French
   uses no-break spaces; and **a name quoted in a sentence ("키 복사", `<b>모니터 배치</b>`) reads as that
   button's own translation**, so nobody is told to press a button that does not exist.
4. After a change to the page's or loader's texts, run `npm run build-client` (the loader carries them).

## Style (how the translations were written)

Meaning first, not word for word. A Korean sentence that explains is rewritten the way a native app in that
language says it. Buttons are verbs in the platform's usual form; status lines are short; explanations live in
tooltips and cards, not in toolbar labels.

| Language | Address | Quotes | Notes |
|---|---|---|---|
| English | you | “ ” | US spelling; sentence case |
| 日本語 | です/ます | 「 」 | full-width punctuation; 「許可」「拒否」 |
| 简体中文 | 你 | “ ” | full-width punctuation |
| 繁體中文 | 你 | 「 」 | Taiwan usage (裝置, 存取金鑰, 用戶端, 螢幕) |
| Español | tú | « » | neutral; *el PC* |
| Français | vous | « » | no-break space before `: ; ! ?` and inside « » (the merge script adds it); Mo, not MB |
| Deutsch | Sie | „ “ | Strg for Ctrl in key names; Entf, Eingabe |
| Português (Brasil) | você | “ ” | Brazilian usage (celular, tela) |
| Русский | вы | « » | plural forms one/few/many; МБ, мс |
| Tiếng Việt | bạn | “ ” | *máy chủ* = host, so *server* for the relay |
| Bahasa Indonesia | Anda | “ ” | |

## What can break the layout, per language, and what was done

| Risk | Languages | Done |
|---|---|---|
| Longer words (30–60 % longer than Korean) | de, ru, fr, es, pt-BR, vi, id | Toolbar scrolls sideways (wheel too) instead of cutting; toasts and the PC list's status lines wrap; dialog buttons move to the next line whole; the start screen's cards grow and the page scrolls; a shorter search placeholder |
| Han characters drawn in Korean shapes | ja, zh-CN, zh-TW | A font per language (`--mr-font`: Yu Gothic UI / Microsoft YaHei UI / Microsoft JhengHei UI, then the Mac and Noto ones) |
| Korean words broken in the middle | ko | `word-break: keep-all`: breaks at spaces, as printed Korean |
| Text without spaces (no word breaks) | ja, zh | `overflow-wrap: anywhere` on the windows' bodies |
| Diacritics stacked above and below the line | vi | Boxes that clip keep a line height of 1.3 or more; looked at in the pictures (nothing cut) |
| Plural forms | ru (and en, es, fr, de, pt-BR) | Plural objects; the test checks every form is there |
| Right-to-left | ar, he | Not offered: the layouts are not mirrored |
| Line breaking without spaces | th | Not offered: not checked |

Checked: `release/test-i18n.js`; the self-test switches the toolbar (by keyboard in its list), its dialogs and
the host window through all 12 languages, and fails when something is cut, wraps inside a button, or makes a page
scroll sideways (`--dump-lang=<folder>` writes pictures of each). The toolbar itself is allowed to scroll: with
three monitors' buttons in a 1264 px window its controls are 383 px too wide in Korean and 896 px in Russian (the
widest). How it fares with one monitor in a full-HD window was not measured. The start screen and the PC list were scanned
the same way at their default and minimum window sizes with a stand-in bridge (pictures looked at).

Not done: a review by native speakers. The translations were written by the agent (Claude) with the style and
glossary above. When someone reports an awkward phrase, fix it in the catalog; the tests keep the rest consistent.
